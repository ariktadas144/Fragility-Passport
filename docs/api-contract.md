# API Contract

Base URL: `http://localhost:8000` (no path prefix — matches the endpoints
listed in the root README). All request/response bodies are JSON. Interactive
docs are also auto-generated by FastAPI at `/docs` once the server is running.

Write endpoints (marked 🔒) require an `X-API-Key` header **only if** the
`API_KEY` environment variable is set on the server; unset by default for
local/demo use (see `.env.example`).

## Health

`GET /health` → `{"status": "ok"}`

## Events — the ML/VLM ingestion endpoint

`POST /events` 🔒 — ingest one raw detection. Full field-by-field spec in
[ml-backend-contract.md](ml-backend-contract.md). Runs the detection through
the risk engine and creates an Alert automatically if risk ≥ MEDIUM.
Returns the persisted event (`EventRead`, see below) with `200`.

`GET /events?dock=07&risk_level=HIGH` — list events, optionally filtered.
Returns `EventListItem[]`: `{id, public_id, dock, start_time_seconds,
risk_level, risk_score, status, behaviors}`.

`GET /events/{id}` — full detail. Returns `EventRead`:
```json
{
  "id": 1, "public_id": "EVT_001", "video_id": 1, "dock": "07",
  "start_time_seconds": 12.0, "end_time_seconds": 18.0,
  "risk_level": "CRITICAL", "risk_score": 87.0, "confidence": 0.95,
  "status": "observed_behaviour",
  "evidence_description": "...", "recommended_action": null,
  "contract_clause_violated": "SKU-class ABC-123: dragging detected. Contract prohibits dragging.",
  "estimated_exposure_inr": 5200.0, "created_at": "2026-09-10T13:31:51",
  "behaviors": ["product_dragged", "rough_handling"],
  "potential_consequence": [],
  "product": {"id": 1, "sku": "ABC-123", "name": "...", "category": "...", "declared_value_inr": 8000.0},
  "evidence_paths": []
}
```
`404` if the event doesn't exist.

## Videos

`POST /videos` 🔒 — register a clip's metadata (`filename`, `dock`,
`source_clip_ref`, `duration_seconds`, `fps`). Not required before posting
events — `POST /events` will auto-create a Video row from `source_clip_ref`
if one wasn't registered.

`GET /videos`, `GET /videos/{id}`.

## Products

`POST /products` 🔒 — `{sku, name, category, declared_value_inr}`. `409` if
the SKU already exists.

`GET /products`, `GET /products/{id}`.

## Fragility Passports

`GET /passports/{product_id}` — the handling contract for a product.
`404` if the product has no passport yet.

`GET /passports/scan/{code}` — **the QR-scan endpoint.** `code` is whatever
the QR code on a box encodes (the product SKU). Returns the same shape as
above. This is what Workstream 5's live booth demo hits.

`POST /passports` 🔒 — `{product_id, max_tilt_deg, max_drop_height_cm,
required_orientation, max_stack_weight_kg, drag_allowed, throw_allowed,
notes}`. `404` if the product doesn't exist, `409` if it already has a
passport.

## Alerts

`GET /alerts?status=ACTIVE` — list alerts, optionally filtered by
`ACTIVE` \| `ACKNOWLEDGED` \| `ESCALATED`.

`POST /alerts/{id}/acknowledge` — body `{"acknowledged_by": "supervisor name"}`.

`POST /alerts/{id}/escalate` — manual escalation (automatic escalation of
stale alerts runs as a background timer, not through this endpoint — see
[risk-engine.md](risk-engine.md)).

## Dashboard

`GET /dashboard/summary` — aggregate-only (dock/risk-level/behavior; never
per individual — see the README's privacy requirement):
```json
{
  "total_events": 17,
  "events_by_risk_level": {"HIGH": 10, "CRITICAL": 6, "MEDIUM": 1},
  "events_by_dock": {"06": 7, "07": 4, "08": 1, "09": 1, "10": 4},
  "events_by_behavior": {"Dragging carton/KD packet": 2, "...": "..."},
  "active_alerts": 17, "escalated_alerts": 0,
  "total_estimated_exposure_inr": 45125.0
}
```

`GET /dashboard/training-gaps` — `{"items": [{"dock": "09", "shift":
"evening", "behavior": "Dragging carton/KD packet", "count": 3}, ...]}`.

## Assistant

`POST /assistant/query` — body `{"question": "which dock had the most
high-risk events?"}`. Returns:
```json
{"answer": "...", "source": "local" | "llm" | "unavailable", "data": null}
```
`source` tells you how the answer was produced: `local` = looked up
directly from the event log (fast, always correct), `unavailable` = the
question asks for data the system doesn't track (SKU/price/injuries — a
grounded refusal, not a guess), `llm` = handed to the pluggable
`ReasoningClient` — currently a stub until Workstream 2 wires up Gemini.

## Reports

`GET /reports/{event_id}` — returns a PDF (`application/pdf`,
`Content-Disposition: attachment`) — the auto-generated claim packet.

`GET /reports/{event_id}?format=html` — the same content as an HTML page,
for a fast preview without downloading a file.

`404` if the event doesn't exist.

## Error shape

Every error follows FastAPI's default: `{"detail": "message"}}` with the
matching status code (`404` not found, `409` conflict, `422` validation
failure — e.g. an unknown behavior code, a confidence outside 0–1, a
timestamp after the video's real duration).
